# Meu Cantinho – Compartilhe Seus Lugares Favoritos

Descubra e compartilhe os melhores lugares com o Meu Cantinho! Seja um café aconchegante, um parque tranquilo ou aquele restaurante incrível, registre seus locais favoritos, avalie com uma nota e adicione uma descrição personalizada. Explore recomendações de outros usuários e encontre novos cantinhos especiais para visitar.

Destaques do app:

✅ Compartilhe seus locais favoritos com notas e descrições.<br/>
✅ Descubra lugares incríveis recomendados por outras pessoas.<br/>
✅ Salve e organize seus cantinhos preferidos.

## Instruções para Executar o Projeto

Siga os passos abaixo para configurar e executar o projeto:

1. **Clone o Repositório**
   ```bash
   git clone https://github.com/massilva/meu_cantinho.git
   cd meu_cantinho
   ```

2. **Instale as Dependências**
   Certifique-se de ter o Flutter e o Dart instalados em sua máquina e execute o comando abaixo para instalar as dependências do projeto:

   ```bash
   flutter pub get
   ```

3. **Gere os Arquivos Necessários**
   Utilize os pacotes `freezed` e `json_serializable` para gerar os arquivos necessários:

   ```bash
   flutter pub run build_runner build
   ```

4. **Execute o Projeto**
   Para rodar o aplicativo, utilize o comando:

   ```bash
   flutter run
   ```

Se precisar de mais informações sobre o Flutter, consulte a [documentação oficial](https://flutter.dev/docs).<br/>
Para dúvidas sobre os pacotes utilizados, veja a [documentação do freezed](https://pub.dev/packages/freezed) e [json_serializable](https://pub.dev/packages/json_serializable).
